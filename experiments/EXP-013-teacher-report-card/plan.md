# EXP-013 立项：教师首次闭环 bench——教师成绩单 #1

## 唯一问题（本轮只回答这一个）

**产 008/009 标签的那台机器（RamenMctsTrainer 全阶段搜索：sn64 / radical 1.4 / use_ucb=false / RamenSelect 合并动作 / 冠军 rollout 评估器），装进选手壳从 turn 0 打满 gen1 采样空间（525 计划，seed 61444），闭环均分是多少？**

- 标签教师不是一个选手：它只存在于采样器抓来的决策点上，没有整局对局可打分。给它补成绩单的唯一机械方式 = 同一台搜索机器装进选手壳（RamenMctsTrainer）从头打到尾。这就是"教师上考场"的可执行含义。
- 它从未被 bench 过。65071.1（EXP-012 v2）是标签自估口径：单步搜索 + 事后按采集 rollout 策略走完 + cross-fit 去乐观偏差——是"教师认为能考多少"的下界代理，不是实测。
- 五点律（学生分 = 教师质量函数）缺的正是这个分母。

## 诚实边界

1. 本实验测的是**教师整局闭环分**，不是"标签自估分"。两者都是"教师"的读数，但一个是实测、一个是期望，结论只能替换"教师实测分"这个量，不许回头拿去解释 65071。
2. 状态分布辨析：采集时的状态来自"默认策略世界"（采样器轨迹），本 bench 的状态来自"教师自己的世界"（教师从 turn 0 打到终）。这正是"教师上考场"的本义。
3. region 口径差异（已知、有意保留）：采集端强制 `ramen_region_strategy=All`；bench 用仓库默认（fixed）。原因：三锚（65438.2 / 65554.2 / 66734.8）全部锁定在仓库默认口径上，改了锚就破。bench 是"教师在三锚同一考场里考试"。

## 方法

- pin：`muxueliunian/umaai-rs-muxue @ d27a6ebd`（与 008/009/011 完全一致）。
- patch 链：006c → 006d → 006e → 006e_fix → 008（rollout 评估器 = 冠军 tokens）→ **013v2**（bench 加 `--trainer mcts` + `--plan-offset`；显式对齐采集四前提，含 `with_ucb(false)`）。
- 保真锚：hw-default **65438.2**、hw-champion **65554.2**、nn-0831 **66734.8**（锚臂 8 rep = 4200 行，与历史逐位可比）。锚差 > 0.05 分 = 作废。
- 裁决：逐局按 `seed` 配对（教师 4 rep 种子 ⊂ 锚臂 8 rep 种子），Δ ± CI、t；t>2 才算数。

## 成本合同（v4，经两次实测标定）

| 实测 | 数值 |
|---|---|
| 熔断 1 局（run 33906965488） | 67.9s 墙钟 / 4 核 ≈ 271 core·s |
| 冒烟 16 局超时（run 33912219777） | ≥225 core·s/局，与熔断一致 |

- 旧预算全作废：8 rep×4200 局 = 316 core·h/臂，任何 ≤24 分片方案都超 180min。
- **v4**：8 rep → **4 rep**（2100 局/臂 ≈ 158 core·h）；score 副口径砍除；20 片 × 27 计划 × 4 局 = 108 局/片 ≈ **122–162 min**，贴线但 <180。
- 4 rep 对统计效力的影响：三档边界 ±1500 vs 配对 SE ≈ ±72（CRN）——**判读零影响**。
- 总墙钟 ≈ 2.3h。

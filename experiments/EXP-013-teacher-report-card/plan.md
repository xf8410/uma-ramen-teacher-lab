# EXP-013 立项：深教师首次闭环 bench——教师成绩单 #1

## 唯一问题（本轮只回答这一个）

**深教师 = `RamenMctsTrainer` 全阶段搜索（每回合对全部合法候选跑 FlatSearch、argmax、一路打到终局），在 gen1 采样空间（525 计划 × 8 局，seed 61444）的闭环均分是多少？**

- 它就是产 008/009 标签的那台机器：每决策点 sn64 搜索、radical 1.4、rollout 评估器 = 冠军 tokens（exp008 补丁后的 `default_rollout_trainer`）。标签生成时它在每个采样决策点上干的就是这件事，只是从没作为选手从头打到尾。
- 它从未被 bench 过一次。已有的 65071.1（EXP-012 v2，run 33897059569）是**标签自估口径**：单步搜索 + 事后按采集 rollout 策略走完 + cross-fit 去乐观偏差——是教师"认为能考多少"的下界代理，不是它上考场的真实成绩。
- 五点律（学生分 = 教师质量函数）现在缺的正是这个分母：教师真分未知，则 66734.8（学生纪录）是已贴顶还是刚起步无从判断。

## 诚实边界（先钉死，防止再次口径漂移）

1. 本实验测的是**深教师整局闭环分**，不是"标签自估分"。两者都是"教师"的读数，但一个是我能造出的最强选手的实测，一个是标签里的价值头期望。结论只能替换"教师实测分"这个量，不许回头拿去解释 65071。
2. 采样分布辨析：采集时的状态来自"默认策略世界"（采样器轨迹），本 bench 的状态来自"教师自己的世界"（教师从 turn 0 打到终）。这正是"教师上考场"的本义——它的分数要在它自己的对局里算。
3. `--mcts-selection pt`（weighted_mean(radical)）为**主口径**，与标签采集的选择口径一致；`score`（结算分均值）为副口径，只报不做裁决。

## 方法

- pin：`muxueliunian/umaai-rs-muxue @ d27a6ebd`（与 008/009/011 完全一致）。
- patch 链：006c → 006d → 006e → 006e_fix → **008**（rollout 评估器 = 冠军 tokens）→ **013**（本补丁：bench 加 `--trainer mcts` + `--plan-offset` 分片）。013 只加选手入口与计划分片，不碰引擎、不碰手写路径。
- 手写臂逐位保真锚：hw-default 必须复现 **65438.2**、hw-champion **65554.2**、nn-0831（ctrl）**66734.8**（模型 artifact 来自主仓 run 33716171772 `EXP-009-model-seed20260831`，与 EXP-011a 同源）。锚差 > 0.05 分 = 补丁链/口径漂移，实验作废。
- 分片：`--plan-offset K --plans 88`，种子流按全局计划号派生（`base + plan_index * 1_000_003`），与全量单跑逐位一致 → 分片结果可与任何历史同种子基准逐局配对。
- 裁决：逐局按 `seed` 列配对（rule_master 对 (计划, 局) 唯一），Δ ± CI、t；t>2 才算数（PRINCIPLES 铁律 4）。

## 成本预算（实测前按上游 426694a 的 12.29s/局外推）

- 单局（全阶段 sn64）≈ 12.3–15s（region 3 点 + super 1 点增量）。
- 冒烟 = 5 计划 × 8 局 × {pt, score} = 80 局 ≈ 每臂 2–3 分钟（4 vCPU）；同时实测单局耗时，校准全量预算。
- 全量 = 每臂 4200 局 ≈ 15–17 CPU·h；6 分片 × 88 计划（588→末片 85 计划截断），每片 ≈ 700 局 ≈ 40 分钟。两臂 + 3 个基线臂 + verdict，一次跑完。

## 事故预案

- 补丁锚点断言失败 = pin 漂移，拒绝打补丁（fail-fast，不许静默）。
- 1 局熔断测试在 build job 内：mcts 臂 30–60 秒内出数，否则就地红，不进 smoke。
- 末分片计划数 525 − 5×88 = 85，切片自带越界 clamp。
- 判读三档写死在 verdict.py，人不现场解释数字。
